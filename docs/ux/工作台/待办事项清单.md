## 四、流程简图

### 1. 项目节点审核
`专员填报(待处置)` → `片区审核(待审核)` → 结束 / 退回填报

### 2～4. 谋划库 / 退库 / 增补库
`专员申报(待处置)` → `分管初审(待审核)` → `片区终审(待审核)` → 结束 / 退回申报

### 5. 领导交办
`领导发起` → `专员处置(待处置)` → `片区审核(待审核)` → `领导查阅(待查阅)` → 结束

### 6. 难题协调
`专员申请` → `分管初审` → `片区终审` → `专员处置` → `分管审核` → `专员确认` → `片区查阅(待查阅)` → 结束

### 7. 预警管理
`系统预警` → `专员处置(待处置)` → 结束

### 8. 项目进度信息
- 资金：`每月 1 号` → `专员填报(待处置)` → 结束（各周期可并存）
- 进度：`每周五晚上` → `专员填报(待处置)` → 结束（各周期可并存）
