# 系统权限整理模版

**用途**：梳理菜单权限、按钮权限、数据权限，供产品/研发/测试对齐。  
**填写说明**：先填「〇、角色与组织」，再按模块填三张主表；单元格统一用符号：

| 符号 | 含义 |
|---|---|
| ● | 有权限 |
| ○ | 无权限 |
| ▲ | 有条件权限（须在备注写清条件） |
| — | 不适用 |

**权限编码建议**（研发落地用）：

- 菜单：`menu:{模块}:{页面}`，例 `menu:workbench:index`
- 按钮：`btn:{模块}:{动作}`，例 `btn:supplement-library:declare`
- 数据：`data:{模块}:{范围}`，例 `data:workbench:self`

### 0.1 角色清单

| 角色编码 | 角色名称 | 所属组织类型 | 说明 | 是否可登录本系统 |
|---|---|---|---|---|
| projectSpecialist | 项目专员 | 责任单位 | 填报/申报/处置 | 是 |

| leader | 交办发起领导 | 区级/市级 | 发起交办、查阅 | 是 |
| admin | 系统管理员 | 系统 | 配置与全量查看 | 是 |
| （增行） | | | | |

### 0.2 组织维度（数据权限常用）

| 维度编码 | 维度名称 | 说明 | 取值来源 |
|---|---|---|---|
| self | 本人 | 仅本人创建/经办 | userId |
| unit | 本单位 | 本责任单位数据 | orgId / unitId |
| district | 本片区 | 片区专员管辖范围 | districtId |
| all | 全部 | 不限范围 | — |
| custom | 自定义 | 按白名单/标签 | 配置表 |

### 0.3 权限原则（可选，项目统一口径）

1. **默认拒绝**：未配置的菜单/按钮不可见、不可点。  
2. **菜单可见 ≠ 可操作**：进得去列表，不等于有申报/审核按钮。  
3. **数据权限优先于按钮**：无数据范围时，按钮有权也不应看到他人单据。  
4. **审核类菜单**：仅审核角色可见；专员走「我的申请/工作台」。

### 1.2 菜单填写注意

- 无页面的「分组节点」可不配权限码，仅叶子菜单控制显隐。  
- 同一业务「申请页 / 初审页 / 终审页」拆三行，避免一个菜单多角色混用。  
- 隐藏菜单但仍可深链打开的，需在备注写「禁止 URL 直达」或单独做路由守卫。

## 六、交付与验收建议

1. **Excel/飞书多维表**：可把本模版三张主表拆成三个 Sheet：`菜单` / `按钮` / `数据`。  
2. **研发对照**：权限码与前端 `v-permission` / 路由 `meta.permission` / 接口鉴权一致。  
3. **测试用例**：每个角色账号走一遍「看不见的菜单、点不了的按钮、看不到的行」。  
4. **变更流程**：新增按钮必须补权限码，禁止只靠前端隐藏。
